# Enterprise Linux Operations Portfolio

Hands-on Linux system administration, incident response, automation, and reliability in RHEL-based environments.

## Overview

This repository supports an enterprise-focused Linux operations portfolio documenting hands-on experience operating Linux systems in production-style environments.

The work emphasizes system administration, service reliability, incident response, automation, and recovery, with a focus on operational judgment rather than theoretical knowledge.

## Scope & Intent

This portfolio is intentionally focused on Linux operations rather than application development.

Projects are designed to reflect real operational scenarios, including misconfigurations, service outages, resource exhaustion, and recovery under pressure. Where applicable, automation and preventative controls are introduced to reduce future risk and operational toil.

## Projects

Each project documents the operation of Linux systems, including failure scenarios, diagnosis, recovery, and preventative improvements.

- **Linux Operations & System Hardening**
- **Service Reliability & systemd Operations**
- **Incident Response & System Recovery**
- **Maintenance Automation Toolkit**
- **Secure & Scheduled Linux Operations**
- **RHEL Enterprise Administration**

Detailed project documentation is available in the `projects/` directory.
